# Evaluation Data

This folder contains evaluation files prepared for TidyLang2026 Challenge.


## Files

- `tl26_lid.txt`
  - file list for language-ID style inference.
  - Contains only file names.

- `tl26_enroll.tsv`
  - Enrollment/reference data.
  - One row per enrollment identity.
- `tl26_pairs.txt`
  - Evaluation pairs for verification-style scoring.
  - Contains only:
    - enrollmentID
    - test file


## `tl26_enroll.tsv` Structure

Tab-separated format, no header.


Example:

`LID_8362W5S    03k2jotoge0.wav    04q8lawk8g6.wav    ...    0pklkrfw7ws.wav`

Interpretation:

- Column 1 is the enrollment identity key.
- Columns 2-9 are enrollment utterances belonging to that identity.
- Use column 1 to match against the first column in `tl26_pairs.txt`.



## Submission Format (Codabench)

You should submit **two prediction files** generated by your model:

1. `tl26_lid.txt` (language identification output)
2. `tl26_pairs.txt` (verification pair score output)

### 1) `tl26_lid.txt` output

- your filename should be `tl26_lid.txt` in your .zip file
- Submit a plain text file with **one column only**.
- Each line must contain the predicted **language ID** for the corresponding input file, in the **exact same row order** as the provided `tl26_lid.txt`.
- Language IDs must use the language-ID space used in the training dataset (fa/en/fr/etc).

### 2) `tl26_pairs.txt` output

- your filename should be `tl26_pairs.txt` in your .zip file
- Submit a plain text file with **one column only**.
- Each line must contain the predicted **similarity score** for that row's `(enrollment_id, test_file)` pair.
- The number of lines and order must be **exactly the same** as the provided `tl26_pairs.txt`.

### Zip packaging rules

- Upload a **single zip file** containing exactly these two files at the zip root:
  - `tl26_lid.txt`
  - `tl26_pairs.txt`
- Do **not** include subfolders.
- Do **not** include extra files.
- File names and zip internal structure must match exactly, otherwise Codabench may reject scoring.
